# App access (instructions for the Play reviewer)

> **DRAFT (I-01) na kontrolu majitelom.**

## v1.0 (`prodLite`)

All functionality is available without special access. No account, no login, no
subscription. Answer in Play Console: "All functionality is available without special access".

Optional note for the reviewer:
> Onboarding takes about a minute (intention, notifications, privacy). The daily set is on
> the Today tab; the Library tab has the full texts; Practice has the morning and evening
> exercises and a private journal.

## v1.1 (`prodFull`, app gate)

Still no login. Note for the reviewer:
> To see the app gate: in the onboarding gate step (or later in Settings > The gate),
> pick an app, allow Usage access and Display over other apps when asked, then open the
> chosen app. The gate shows a few cards; "Emergency" always opens the app.

# Store listing (Google Play)

> **DRAFT (I-01) na kontrolu majitelom.** Texty v `en-US/` su navrh, pred
> zverejnenim ich skontroluje majitel (ton, nazov, tvrdenia o funkciach).

| File | Play field | Limit |
|---|---|---|
| `title.txt` | App name | 30 chars |
| `short_description.txt` | Short description | 80 chars |
| `full_description.txt` | Full description | 4000 chars |
| `release_notes_<tag>.txt` | Release notes ("What's new") | 500 chars |

Rules: calm tone, short sentences, no emoji, no exclamation marks, no
"best"/"#1"/"free"; no promise the app does not keep (gate only in `full`,
v1.1, preto v1.0 popise nie je); source names exactly as on the
"Sources & licenses" screen and in `content.db` (`work.title`, prekladatel,
rok). Nespominat nazov digitalnej kniznice, z ktorej je prepis textu.
